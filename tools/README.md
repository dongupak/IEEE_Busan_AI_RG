# tools — 세미나 포스터 생성기

연구회 홈에서 **Ctrl + E**(맥은 ⌘ + E)를 누르면 비밀번호를 물어보고, 통과하면 포스터 생성기로 들어갑니다.
입력한 내용으로 **포스터 웹 페이지 + 폴더 + 홈 화면 항목**이 한 번에 만들어집니다.

## 파일

| 파일 | 역할 |
|------|------|
| `gate.js` | Ctrl+E 비밀번호 모달. 비밀번호 대신 **SHA-256 해시**를 저장해 두고 입력값의 해시를 비교합니다. |
| `poster-builder.html` | 입력 폼 + 실시간 미리보기 + 저장 화면 |
| `poster-template.js` | 포스터 HTML · `README.md` · 홈 화면 항목을 만드는 템플릿 |
| `qr.js` | 등록 폼 URL을 QR 코드(SVG)로 바꾸는 인코더 (외부 라이브러리 없음) |

## 쓰는 법

폴더에 바로 저장하려면 **로컬 서버 + Chrome/Edge**가 필요합니다 (브라우저의 File System Access API 사용).

```bash
cd ~/GitRepos/IEEE_AI_RG
python3 -m http.server 8000
```

1. Chrome에서 `http://localhost:8000/` 접속
2. **Ctrl + E** → 비밀번호 입력
3. 연도 · 회차 · 연사 · 소속 · 약력 · 제목 · 강연 내용 · 등록 폼 URL · 기타 안내 · 문의처 입력
   (오른쪽에 포스터가 실시간으로 그려집니다)
4. **폴더 선택하고 저장하기** → 저장소 최상위 폴더(`IEEE_AI_RG`)를 선택

연도 2026 · 회차 7이면 다음이 만들어집니다.

```
2026_RG7/
├── poster/index.html   ← 포스터 웹 페이지 (인쇄·PDF 저장 가능)
├── README.md           ← 회차 안내
└── pics/README.md      ← 행사 사진 넣을 폴더
```

그리고 최상위 `index.html`의 `lectures` 배열에 7차 항목이 추가되어,
홈 화면 목록·네비게이션에 7차가 나타나고 **포스터 자세히 보기** 버튼이 `2026_RG7/poster/`로 연결됩니다.
최상위 `README.md`에도 회차 안내가 덧붙습니다(체크박스로 끌 수 있음).

Chrome이 아니거나 `file://`로 열어 저장이 막히면 **파일로 내려받기**를 쓰세요.
내려받은 파일을 위 경로에 옮기고, 함께 표시되는 항목 코드를 `index.html`의
`/* LECTURES:END */` 바로 위에 붙여넣으면 결과가 같습니다.

## 주의

* `index.html`의 `/* LECTURES:BEGIN */` · `/* LECTURES:END */` 주석은 삽입 위치 표시입니다. 지우지 마세요.
* 같은 회차를 다시 저장하면 홈 화면 항목은 **중복되지 않고 교체**되며, 포스터 파일은 덮어쓸지 물어봅니다.
* 비밀번호 검사는 브라우저 안에서만 이루어집니다. 소스에 해시가 들어 있으므로
  "아무나 못 열게 하는 잠금" 수준이지 서버 인증 같은 보안은 아닙니다.
  실제로 감춰야 하는 내용은 이 저장소에 두면 안 됩니다.
* 발표 자료(PDF)와 행사 사진은 특강이 끝난 뒤 `2026_RGn/`, `2026_RGn/pics/`에 직접 넣고
  `index.html`의 해당 항목에서 `pics` 배열과 `files` 목록을 채우면 됩니다.
